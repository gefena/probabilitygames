# Probability Games

An interactive educational platform featuring 20+ probability games designed to build intuition through play, simulation, and data visualization.

## 🎮 Overview

This project provides a collection of interactive games and simulations categorized into four learning tiers, progressing from basic concepts to complex statistical phenomena:

1.  **Start Here**: Simple, single-interaction games (Coin Flip, Lucky Dice, Candy Jar, etc.)
2.  **Go Deeper**: Strategy and decision-making games (Roll & Race, Pizza Builder, Greedy Pig, etc.)
3.  **Crack the Code**: Combinatorics and guessing games (Guess the Phone, Hack the Password)
4.  **Patterns in Chaos**: Advanced simulations and visualizations (Galton Board, Monte Carlo π, Monty Hall, etc.)

## 🚀 Features

-   **Interactive Simulations**: Real-time feedback and data generation.
-   **Educational Quizzes**: Embedded learning checks for each game.
-   **Multi-language Support**: Full support for English and Hebrew (RTL).
-   **Responsive Design**: Modern, mobile-friendly UI built with Tailwind CSS.
-   **Polished Animations**: Smooth transitions and interactive feedback using Framer Motion.
-   **Data Visualization**: Charts and histograms powered by Recharts.

## 🛠️ Tech Stack

-   **Framework**: React 19 (Vite)
-   **Styling**: Tailwind CSS, PostCSS, Autoprefixer
-   **Animations**: Framer Motion
-   **Charts**: Recharts
-   **i18n**: i18next, react-i18next
-   **Icons**: Lucide React
-   **Deployment**: Ready for Vercel

## 💻 Getting Started

### Prerequisites

-   Node.js (v18 or higher recommended)
-   npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone git@github.com:gefena/probabilitygames.git
   cd probabilitygames
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Open your browser and navigate to `http://localhost:5173`

### Building for Production

To create a production-ready build:
```bash
npm run build
```
The output will be in the `dist/` directory.
