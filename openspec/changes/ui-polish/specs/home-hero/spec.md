## ADDED Requirements

### Requirement: Home page welcome area
The home page SHALL display a compact visual welcome area above the first game tier. It SHALL include the site subtitle and a light card background so the eye has an anchor before the game grid begins.

#### Scenario: Welcome area visible above game grid
- **WHEN** the user visits the home page
- **THEN** a styled welcome card is visible above the "Start Here" tier containing the site subtitle

#### Scenario: Welcome area is compact
- **WHEN** the user views the home page on any device
- **THEN** the welcome area takes no more than ~120px of vertical space so the game grid is visible near the top of the screen
