### Requirement: Fraction-based bridge generation
Bridge probabilities SHALL be generated by randomly selecting from a curated pool of clean fractions: 1/2, 1/3, 2/3, 3/4, 4/5, 5/6, 9/10, 3/5, 2/5. Each bridge SHALL store its numerator, denominator, and equivalent percentage.

#### Scenario: Bridge values are always clean fractions
- **WHEN** a new race is generated
- **THEN** every bridge probability corresponds to one of the 7 curated fractions

#### Scenario: Survival is computed from fractions
- **WHEN** combined path survival is calculated
- **THEN** it is computed by multiplying numerators and denominators exactly, not from the rounded percentage

### Requirement: Fraction/percentage display toggle
A toggle control SHALL be visible on the BridgeQuestPage allowing the player to switch all bridge displays between percentage form (e.g. "75%") and fraction form (e.g. "3/4"). The toggle SHALL default to percentage mode.

#### Scenario: Default is percentage mode
- **WHEN** the page loads
- **THEN** all bridge pills show percentages

#### Scenario: Toggle switches all bridges to fractions
- **WHEN** the player activates the fraction toggle
- **THEN** all bridge pills immediately display as fractions (e.g. "3/4") instead of percentages

#### Scenario: Toggle switches back to percentages
- **WHEN** the player deactivates the fraction toggle
- **THEN** all bridge pills return to percentage display

### Requirement: Survival preview respects display mode
The combined survival preview shown when a player taps a path SHALL display the survival probability in the currently active display mode. In fraction mode, it SHALL show the exact fraction product (e.g. "3/8").

#### Scenario: Fraction mode survival preview
- **WHEN** the player taps a path while fraction mode is active
- **THEN** the preview shows combined survival as a simplified fraction (e.g. "3/8 make it through")

#### Scenario: Percentage mode survival preview (unchanged)
- **WHEN** the player taps a path while percentage mode is active
- **THEN** the preview shows combined survival as "N in 100 make it through" (existing behaviour)
